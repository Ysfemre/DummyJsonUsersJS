# User List Project (Vanilla JS)

This is a dynamic user listing application built using fundamental HTML, CSS, and JavaScript.

## Project Purpose

The main goal of this project is to practice the cornerstones of modern JavaScript. It specifically focuses on:

* Fetching data from an external API using `fetch` (Asynchronous JavaScript).
* Processing the fetched data and dynamically rendering it into the HTML (DOM).
* Creating user interaction using Event Listeners (`addEventListener`).
* Performing DOM manipulation for live filtering (search) and toggling content visibility.

## Features

* **API Integration:** The application fetches user data from the `https://dummyjson.com/users` API and lists them on the screen.
* **Live Search (Filtering):** The search box at the top is responsive to every keystroke (`input`) and filters the user cards in real-time.
* **Toggle Details:** The "Show Details" button on each user card toggles the visibility of extra information (like email, phone, and address) for that specific user.
